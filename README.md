# Vishwajeet Pawar — Portfolio

Premium Product Engineer-style portfolio built with React, Vite and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```

## What is included

- Larger, recruiter-friendly typography
- Product-engineering visual system
- Animated Data × AI technology orbit on the homepage
- Framer Motion entrance and interaction animations
- Light/dark mode
- Responsive mobile layout
- Scroll progress indicator
- Animated project case studies
- Experience, skills, education, certifications and contact sections
